# Gebruiksaanwijzing

### opladen / vervangen batterijen
Haal de batterijen uit de batterijhouder en steek ze in de oplader, steek de oplader in het stopcontact en wacht tot de lampjes groen zijn

### draadloze communicatie
#### verbinding maken
Installeer de app serial bluetooth commands. Verbind eerst is via bluetooth met de hc05, dan kan je deze toevoegen in de app. Druk op het verbind icoontje en wacht tot je ziet staan: Verbonden

#### commando's
debug [on/off]: typ d, deze toggelt debug mode  
start, typ t  
stop, typ o  
set cycle [µs]: typ cycle en dan de waarde erna bv cycle10 = 10ms  
set kp [0..]: typ kp en dan de waarde  
set ki [0..]: typ ki en dan de waarde  
set kd [0..]: typ kd en dan de waarde  
v: toont alle instellingen  
h: menu waar alle commands in staan

### kalibratie
zet alle sensoren op wit en typ c, zet daarna alle sensoren op zwart en druk nog is c
